# Sprint Retrospective – Sprint 1: Core User Features

**Date:** August 20, 2026  
**Participants:** PM, Dev Team, UX/UI Designer  
**Sprint Goal:** Build user registration, restaurant discovery, and cart management

---

## ✅ What Went Well
- Registration flow was completed ahead of schedule
- Restaurant list API integration was smooth
- Team collaboration was strong — daily standups were productive

---

## ❌ What Could Be Improved
- GPS permission handling — users who denied access were stuck
- Performance issues — restaurant list took 3–5 seconds to load
- Some user stories were too vague → confusion during development

---

## 💡 Lessons Learned
1. Acceptance criteria should be more detailed from the start
2. Always have a fallback for features that rely on user permissions
3. Performance optimization should be part of the definition of "done"
